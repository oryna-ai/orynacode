# 工具系统详解

## . 工具系统详解

OrynaCode 为 AI 提供了丰富的内置工具。每个工具执行时会在对话中显示对应的图标和状态。

### 8.1 Shell（bash）

**图标**：`$`

执行终端命令。输出默认可折叠，点击展开查看完整输出。

![Shell 工具](images/tool-shell.png)

### 8.2 Read

**图标**：`→`

读取文件内容。支持指定行范围。展示文件名、行数和加载的文件列表。

### 8.3 Glob

**图标**：`✱`

按文件名模式搜索（如 `**/*.test.ts`）。展示搜索模式和匹配结果数量。

### 8.4 Grep

**图标**：`✱`

按正则表达式搜索文件内容。展示搜索模式和匹配数量。

### 8.5 Edit

**图标**：`←`

精确文本替换，展示文件路径和 inline diff。相比直接修改文件更安全。

![Edit 工具](images/tool-edit.png)

### 8.6 Write

**图标**：`←`

创建或覆盖文件。展示文件路径和代码预览。

### 8.7 Apply Patch

**图标**：`%`

应用 unified diff 补丁。支持批量修改多个文件，显示每个文件的 diff。

### 8.8 WebFetch

**图标**：`%`

获取网页内容并解析。用于查询在线文档、API 参考等。

### 8.9 WebSearch

**图标**：`◈`

搜索互联网。展示搜索提供商、查询词和结果数量。

### 8.10 Task（子代理）

**图标**：`│`（运行中）/ `✓`（已完成）

创建子代理执行子任务。展示子代理标题、工具调用进度和耗时。

### 8.11 TodoWrite

**图标**：`⚙`

创建和更新任务列表。以清单形式展示。

![TodoWrite 工具](images/tool-todowrite.png)

### 8.12 Question

**图标**：`→`

向用户提问。展示问题和选项。

### 8.13 Skill

**图标**：`→`

加载预定义的 Skill 指令集。展示 Skill 名称。

### 8.14 工具显示控制

- 工具完成后默认折叠。展开/折叠：点击或按 `→`/`←`
- 使用 `/toggle-generic-tool-output` 切换通用工具输出的显示
- 使用 `/toggle-actions` 切换所有工具详情的显示
